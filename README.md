Connect Four Game 🎮

About the Project

Connect Four is a two-player strategy game built using HTML, CSS, and JavaScript. Players take turns dropping colored discs into a grid. The first player to connect four discs horizontally, vertically, or diagonally wins.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Two-player gameplay
- Interactive game board
- Automatic win detection
- Score tracking
- Play Again and Reset Score options

How to Play

1. Open the game in your browser.
2. Players take turns choosing a column.
3. Connect four discs in a row to win.
4. Click Play Again to start another game.

Project Files

- "index.html" — Game structure
- "style.css" — Game design and styling
- "script.js" — Game logic and functionality
